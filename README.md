## Featured projects

### 🤖 [PulseAI](https://github.com/ShkAmmarHussain/PulseAI)
A fully offline, voice-first desktop AI companion for Windows. Say "Hey Jarvis" and it listens, thinks and talks back, with the LLM running locally through LM Studio. Built with a Tauri (Rust) UI and an async Python backend, using local wake-word detection, faster-whisper speech-to-text, Kokoro TTS and a multi-agent core with a permission system for PC control.
